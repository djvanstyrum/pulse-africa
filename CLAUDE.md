# Pulse Africa

## About this project

Pulse Africa is a non-profit foundation that helps dance schools in Africa. Many of these schools already have a large following on social media.

Goals:
- Help the dance schools become more visible.
- Build AI agents (helpers that can do tasks on their own) for these schools, so they can work more efficiently and earn more income for their organisation.

Example dance schools: Smash Talent Uganda, Masaka Kids, and many more.
